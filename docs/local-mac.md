# Заметки о ранее настроенном Mac

В этом рабочем каталоге установлен Python 3.12 с OpenSSL:

- базовый интерпретатор: `.python/` (не удаляйте, пока используете окружение);
- виртуальное окружение: `.venv312/`;
- `.venv` — ссылка на `.venv312`, позволяющая использовать старый путь PyCharm;
- прежнее окружение Python 3.9/LibreSSL сохранено в `.venv39-backup/`.

Эти каталоги исключены из Git и не нужны на Amvera или другом компьютере.
После обновления установите зависимости: `.venv/bin/python -m pip install -r requirements.txt`.
Запуск: `.venv/bin/python -m app.main`. Остановите прежний процесс перед запуском.
Если PyCharm показывает старую версию Python, выберите `.venv312/bin/python` и
перезапустите конфигурацию. Уже работающий процесс не меняет интерпретатор автоматически.

В данном окружении Python 3.9 с LibreSSL не проходил TLS к GigaChat.
Корневой сертификат хранится в `certs/russian_trusted_root_ca_pem.crt`, путь к нему
задаётся через `.env`. Эта заметка не означает, что текущая версия бота проверена
реальными запросами: новый код проверяется только автоматическими тестами с подменой транспорта.
